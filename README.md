# StreamlitData-waterQuality- Biscayne Bay Water Quality Dashboard

**Course:** CIS 3590 - Internship-Ready Software Development  
**Live App:** https://appdata-waterquality-gjcshqexyez47iujasfgwr.streamlit.app/

---

## App Purpose
This interactive web app enables users to upload, analyze, and visualize marine water quality sensor data from Biscayne Bay to identify environmental trends and spatial patterns.

---

## Features 
* **Data Management:** File uploader supporting custom CSV files with fallback to a default Biscayne Bay dataset.
* **Interactive Data Table:** Display raw data with dynamic column multi-select filters and statistical summaries.
* **Plotly Visualizations:**
  * **Line Chart:** Dynamic time-series selector for any water parameter.
  * **2D Scatter Plot:** Temperature vs. Salinity correlation.
  * **3D Scatter Plot:** Depth topography visualization of the bay floor.
  * **Geospatial Map:** GPS coordinates with color-coded temperature readings.
* **Structured UI:** Organized into clear tabs (*Overview*, *Data Display*, *Charts*, *Maps*, and *Agile Info*).
